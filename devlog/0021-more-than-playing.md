# #21 — ただ遊ぶだけじゃない

コントローラーでゲームを選び、PLAYして、Save Stateで好きな瞬間へ戻れる。

ここまで来ると、NOA Systemはかなり普通に「ゲームを遊べる」ようになってきました。

でも、そこで少し欲が出ます。

**ゲームを起動したあとも、NOA Systemの中にいる感じが欲しい。**

今回は、プレイ中に呼び出せるOverlay / System Menuの基盤を作りました。

---

## F5とF9を、ゲーム機の操作へ戻す

前回までのSave Stateは、開発用のキー操作でした。

```text
F5 : Save State
F9 : Load State
ESC: Exit Game
```

機能としては動いています。

でも、ゲームパッドを握って遊んでいる途中でKeyboardへ手を伸ばすのは、やっぱり少し違います。

そこでプレイ中にOverlayを開き、そこから既存の機能を呼べるようにしました。

```text
RESUME
SAVE STATE
LOAD STATE
RESET
EXIT GAME
```

新しいSaveやLoadを作り直したわけではありません。

これまで作ってきた安全な処理へ、ゲーム機らしい入口をつけた形です。

---

## メニューを開く入力は、ゲームへ渡さない

Overlayを開く暫定操作は、`D-Pad Down + Select` の同時押しです。

この入力はまずNOA System側で判定され、Overlayを開いたframeではゲーム本体を進めません。

そのため、メニューを出すために押したDownやSelectが、そのままゲーム内の入力として流れ込むことはありません。

Overlayを開いた瞬間にまだボタンを押しっぱなしでも、その入力を「新しく押された」と誤認してカーソルが勝手に動かないようにしています。

以前Game ListからGame Detailへ移動したときに起きた、押しっぱなし入力の持ち越し問題。

あのときの経験が、ここでもそのまま役に立ちました。

---

## メニューを開いたら、ゲームも音も止める

Overlay表示中はゲームをpauseします。

Coreの実行を止め、Audioもpauseします。

Resumeしたときにpauseしていた時間が一気に処理されたり、古いAudio sampleが遅れて鳴ったりしないよう、その境界も整理しました。

単に画面の上へ文字を重ねただけではなく、

**「今はゲームを遊んでいる時間ではなく、NOA Systemを操作している時間」**

へちゃんと切り替えています。

---

## Exitも、近道を作らない

Overlayから`EXIT GAME`を選んでも、特別な終了処理は作っていません。

これまで使っていた正常なSession終了経路へ戻します。

そこでSRAMを保存し、ゲームをUnloadし、Frontendへ帰る。

Save StateもLoad Stateも同じです。

Overlayは既存処理を呼び出すだけで、それぞれの安全性を二重実装しません。

機能が増えてきたからこそ、入口が増えても中身を増殖させないことが大事になってきました。

---

## 少しだけ「NOAらしい」画面になった

この段階のOverlayは、まだ完成デザインではありません。

半透明の背景にmenu項目とselectionがある、かなり素朴なものです。

でも実際のゲーム画面の上にNOA System自身の操作が現れるようになると、印象は思った以上に変わりました。

![プレイ中のOverlay Menu](https://github.com/user-attachments/assets/2267d507-6640-4d45-949f-2e00135786c1)

ゲームを起動するためのLauncherではなく、遊んでいる最中にも存在するSystemになり始めます。

ここは、機能以上に大きな変化だった気がします。

---

## 「何ができるか」から、「どういうものか」へ

これまでの開発では、まず必要な機能を一つずつ成立させてきました。

ROMを読む。

Saveを残す。

コントローラーで遊ぶ。

Stateを保存して、戻る。

その積み重ねができてきたことで、少しずつ別の問いを考えられるようになります。

**NOA Systemは、遊んでいる人にとってどういう存在であってほしいのか。**

Overlay Menuは小さな機能ですが、その問いが画面に初めて出てきた場所なのかもしれません。

ただゲームを動かす箱から、少しずつ「らしい」ゲーム機へ。

---

## micから

やっとNOA-SYSTEMにて「ゲームをただ遊ぶだけじゃない」という状況になってきたので、
ゲーム内にオーバーレイメニューでも作るのどうかな？と相談。

いつも通りEchoは「最高のタイミングだと思います！」と言ってくれるので早速簡単に仕様検討。
そしてしっかりとEchoがIssueに起こしてくれたので確認してClaudeさんに依頼。

最初にNOA-SYSTEMの思想を話し込んであるので、初手で全く問題のないメニューを作ってくれた。
いいぞ。ちょっとずつ「らしく」なってきた。
