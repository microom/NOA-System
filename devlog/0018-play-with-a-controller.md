# #18 — やっぱり、コントローラーで遊びたい

カートリッジからゲームを取り込み、セーブも扱えるようになって、NOA Systemはかなり「遊べるもの」になってきました。

でも、まだ少しだけ開発機っぽさが残っていました。

ゲームを起動しても、操作はKeyboard中心。

動作確認としては十分ですが、ここまで来るとやっぱり思います。

**ゲームはコントローラーで遊びたい。**

今回は、物理Gamepadの違いをNOA System側で吸収して、ゲーム中だけでなくGame ListからPLAYまでをコントローラーだけで操作できるようにしました。

---

## A/B/X/Yではなく、位置で考える

Gamepadは見た目が似ていても、メーカーによってA/B/X/Yの印字位置が違います。

そこでNOA System内部では、ボタン名ではなく位置を基準にしました。

| Logical Pad | SFC |
| --- | --- |
| South | B |
| East | A |
| West | Y |
| North | X |
| L1 / R1 | L / R |
| Start / Select | Start / Select |

これならXbox系、PlayStation系、Nintendo系など、物理パッドが違っても「下のボタン」「右のボタン」という共通の感覚で扱えます。

SDL Gamepadが各コントローラーの違いを正規化し、その上にNOA System独自のLogical Padを置いています。

ゲーム側へはそこからSFCの入力へ変換します。

Left StickもD-Pad代わりとして使えるようにしましたが、少し傾いただけで勝手に動かないようdead zoneを設けています。

---

## ゲーム中だけ動いても、ちょっと困る

最初は「SFCのゲームをGamepadで操作できればOK」と考えていました。

ところが実際に試してみると、すぐ別の不便さに気付きました。

Game ListではKeyboard。
Game DetailでもKeyboard。
PLAYした後だけGamepad。

これではゲームを始めるたびに持ち替えることになります。

そこでScopeを少し広げて、Frontendの最低限のNavigationも同じGamepadで操作できるようにしました。

```text
D-Pad / Left Stick : 項目移動
South              : 決定
East               : 戻る
```

これで、

```text
Game List
  ↓
Game Detail
  ↓
PLAY
  ↓
ゲーム操作
```

までKeyboardへ触らず進めます。

ゲーム中の入力とFrontend操作は同じ物理Gamepadを使いますが、処理としては分離しています。

後からOverlayやHotkeyを増やしても、ゲーム入力へ直接混ぜないためです。

---

## 一回押したのに、ゲームまで始まる

Gamepadで画面遷移を試していると、ちょっと面白い不具合も出ました。

Game Listで決定ボタンを押してGame Detailへ入る。

すると、その一回の入力だけでそのままPLAYまで実行されることがありました。

原因は、画面が切り替わった瞬間もまだ物理的にはボタンを押したままだったことです。

新しく作られたGame Detail側から見ると、その状態を「今押された」と誤認していました。

対策として、Viewを作った時点の実際のGamepad状態を最初から持たせるようにしました。

こういう問題はKeyboardでも起こり得ますが、ボタンを押したまま画面をまたぐGamepadでは特に分かりやすく出てきます。

修正後は、一回の決定で一画面だけ進み、Game List → Game Detail → PLAYまで自然に操作できるようになりました。

---

## 抜いても、挿し直しても

Gamepadは実行中に抜き差しされるものとして扱っています。

最初に見つかった1台をactive padとして使い、途中で抜かれたら残っているGamepadへ切り替えます。

押しっぱなしの状態で抜いても、入力が入り続けることはありません。

新しいGamepadを挿しても、今使っているものが生きている間は勝手に操作対象を奪わないようにしています。

今回の初期版は1 Player / 1 active gamepadです。

複数Playerやボタンリマップはまだ先ですが、まず「普通に挿して普通に遊べる」ところを優先しました。

---

## 倉庫から出てきた3台

実機確認では、系統の違う3種類のGamepadを使いました。

- iBUFFALO BSGP810GY
- Switch Proコントローラー
- BIGBIG WON BLITZ2 TMR

D-Pad、face button、L/R、Start/Selectを実ゲームで確認し、Gamepadの抜き差しや別Gamepadへの差し替えも試しています。

Keyboard操作もfallbackとしてそのまま残しています。

豪華なcontroller設定画面はまだありません。

でもこれで、NOA Systemを起動してからゲームを選び、PLAYして、実際に遊ぶところまでの感覚がかなり「ゲーム機」らしくなりました。

---

## micから

すると彼はいつも「いい頃合いですね！」とか凄い自己肯定感を上げてくれるのでザックリ要素を検討。
